# 🤖 AI-Powered Daily AI News Automation

An AI-powered workflow that collects AI news from RSS feeds,
summarizes articles using Google Gemini, and delivers the
generated news digest directly to Gmail.

## 🎯 Project Overview

This project automates the process of collecting and summarizing
Artificial Intelligence news using an AI-powered workflow.

It integrates RSS feeds, Google Gemini, and Gmail to create
a streamlined news delivery system.

## ✨ Features

- Automated AI news collection using RSS feeds
- Processes multiple news articles
- AI-powered summarization using Google Gemini
- Automated Gmail delivery
- Schedule-based workflow execution
- Successfully tested with real email delivery

## 🛠️ Technologies Used

- RSS Feeds
- Google Gemini
- Large Language Models (LLMs)
- Workflow Automation
- Gmail Integration

## ⚙️ Workflow

Schedule Trigger
      ↓
RSS Read
      ↓
Limit Articles
      ↓
Aggregate News
      ↓
Google Gemini LLM Chain
      ↓
Send Email via Gmail

## 🚀 How It Works

1. The schedule trigger initiates the workflow.
2. RSS feeds provide the latest AI news articles.
3. The Limit node controls how many articles are processed.
4. The Aggregate node combines the collected information.
5. Google Gemini generates a news summary.
6. Gmail sends the summary to the configured email address.
